# Documentation utilisateur — GestionTâches

## Présentation

GestionTâches est un outil de gestion de projets collaboratifs de type Jira. Il permet de créer des projets, planifier des sprints, organiser des epics, gérer des tâches, communiquer via un chat intégré et recevoir des notifications en temps réel.

Cette documentation s'adresse aux utilisateurs finaux de l'application. Elle décrit, étape par étape, comment utiliser chaque fonctionnalité disponible dans l'interface.

## Prérequis

- Un navigateur web moderne (Chrome, Firefox, Edge, Safari) à jour
- Une connexion internet
- Un compte utilisateur fourni par l'administrateur de votre espace (ou créez votre propre compte via la page d'inscription)
