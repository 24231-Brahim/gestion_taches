# Messagerie instantanée

Le chat intégré permet de communiquer en temps réel avec les membres de votre projet. Il est accessible depuis la page de chaque projet.

## Accéder au chat

1. Ouvrez un projet.
2. Dans la barre latérale, cliquez sur **Discussion**.
3. Le chat s'ouvre avec trois volets :
   - **Gauche** : liste des conversations
   - **Centre** : messages de la conversation sélectionnée
   - **Droite** : liste des membres du projet

💡 Astuce : le canal **# Général** est créé automatiquement pour chaque projet et est sélectionné par défaut à l'ouverture.

## Interface du chat

### Sur ordinateur (écran large)

- **Volet gauche (280 px)** : liste des conversations groupées par type
- **Volet central** : en-tête de la conversation, liste des messages, zone de saisie
- **Volet droit (240 px)** : liste des membres avec indicateur de présence

### Sur mobile (écran petit)

- L'interface passe en mode mono-panneau : vous voyez soit la liste des conversations, soit les messages d'une conversation.
- Un bouton **retour** dans l'en-tête permet de revenir à la liste des conversations.

## Envoyer un message

1. Sélectionnez une conversation dans le volet gauche (ou démarrez une conversation directe — voir ci-dessous).
2. Dans la zone de saisie en bas du volet central, tapez votre message.
3. Appuyez sur la touche **Entrée** pour envoyer, ou cliquez sur le bouton d'envoi (icône avion en papier).
4. Pour aller à la ligne sans envoyer, utilisez **Maj + Entrée**.

💡 Astuce : la zone de saisie s'agrandit automatiquement au fur et à mesure que vous tapez.

## Répondre dans le canal général

1. Cliquez sur le canal **# Général** dans la liste des conversations.
2. Écrivez votre message et envoyez-le.
3. Tous les membres du projet verront votre message dans ce canal.

## Démarrer une conversation directe

1. Dans le volet droit, cliquez sur le nom d'un membre.
2. Une conversation privée s'ouvre automatiquement dans le volet central.
3. Écrivez votre message et envoyez-le. Seul vous et le membre concerné verrez cet échange.

## Modifier un message

1. Survolez le message que vous avez envoyé.
2. Cliquez sur l'icône **crayon**.
3. Modifiez le texte dans la zone qui apparaît.
4. Appuyez sur **Entrée** pour sauvegarder ou sur **Échap** pour annuler.

⚠️ Attention : vous ne pouvez modifier que vos propres messages.

## Supprimer un message

1. Survolez le message que vous avez envoyé.
2. Cliquez sur l'icône **corbeille**.
3. Confirmez la suppression dans la boîte de dialogue.

Le message est alors marqué comme supprimé et son contenu est remplacé par "Message supprimé".

⚠️ Attention : la suppression est définitive. Vous ne pourrez pas récupérer le message.

## Voir qui est en ligne

- Dans le **volet droit**, chaque membre affiche une **pastille verte** (en ligne) ou **grise** (hors ligne) à côté de son avatar.
- Le texte indique explicitement **"En ligne"** ou **"Hors ligne"**.
- Dans l'en-tête de la conversation, un compteur indique le nombre de membres en ligne (ex: "2 en ligne").

💡 Astuce : votre propre présence est mise à jour automatiquement toutes les 30 secondes.

## Consulter les messages précédents

1. Faites défiler la conversation vers le haut.
2. Cliquez sur le bouton **"Messages précédents"** qui apparaît pour charger l'historique plus ancien.
3. Répétez l'opération pour remonter plus loin dans l'historique.

## Naviguer entre les conversations

- Dans le **volet gauche**, cliquez sur une conversation pour l'ouvrir.
- Les conversations sont groupées en deux sections : **General** (canaux de projet) et **Direct** (messages privés).
- Un indicateur visuel montre le nombre de messages non lus par conversation.
