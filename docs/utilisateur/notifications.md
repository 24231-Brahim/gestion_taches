# Notifications

Les notifications vous informent automatiquement des événements importants qui vous concernent : création ou modification de tâches, assignations, changements de statut, etc.

## Voir vos notifications

### Depuis la barre supérieure

1. Cliquez sur l'icône **cloche** en haut à droite de l'écran.
2. Un menu déroulant s'affiche avec les dernières notifications (jusqu'à 5).
3. Chaque notification indique :
   - Le message (ex: "Tâche 'Corriger le bug' créée")
   - La date et l'heure
   - Le titre de la tâche concernée (si applicable)

4. Cliquez sur **"Voir tout"** pour accéder à la page complète des notifications.

### Depuis la page Notifications

1. Dans la barre latérale ou via le menu des notifications, cliquez pour accéder à la page **Notifications** (`/notifications`).
2. La page liste toutes vos notifications avec pagination.

## Types de notifications

Vous recevez une notification lorsque :

- Une tâche vous est assignée
- Le statut d'une tâche que vous suivez change
- Un commentaire est ajouté sur une tâche que vous suivez
- Une tâche dont vous êtes responsable est modifiée

## Marquer une notification comme lue

1. Survolez la notification (dans le dropdown ou sur la page).
2. Cliquez sur l'icône ou le bouton prévu à cet effet.
3. La pastille de notification disparaît et le compteur sur la cloche se met à jour.

## Marquer toutes les notifications comme lues

1. Sur la page **Notifications**, cliquez sur le bouton **"Marquer tout comme lu"** en haut à droite.
2. Toutes les notifications sont marquées comme lues et le badge sur la cloche disparaît.

## Naviguer vers l'élément concerné

1. Cliquez sur une notification.
2. Vous êtes redirigé(e) vers la tâche, le sprint ou le projet concerné, selon le type de notification.

💡 Astuce : si la notification concerne une tâche, le panneau de détail de la tâche s'ouvre directement.

## Consulter le détail d'une notification

1. Sur la page Notifications, cliquez sur une notification pour ouvrir la fenêtre de détail.
2. Le détail affiche :
   - Le message complet
   - La date et l'heure
   - Le statut (lu / non lu)
   - Le titre de la tâche associée (si applicable)
