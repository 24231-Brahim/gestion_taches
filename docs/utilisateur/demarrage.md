# Démarrage — connexion, inscription et navigation

## Créer un compte

1. Ouvrez votre navigateur et accédez à l'application.
2. Cliquez sur **"Créer un compte"** en bas de la page de connexion.
3. Renseignez les champs suivants :
   - **Nom d'utilisateur** : choisissez un identifiant unique (lettres, chiffres, sans espaces)
   - **Email** : votre adresse email professionnelle
   - **Mot de passe** : au moins 4 caractères
   - **Confirmation du mot de passe** : retapez le même mot de passe
4. Cliquez sur le bouton **"Enregistrement"**.

💡 Astuce : la barre de couleur sous le champ mot de passe indique la robustesse de celui-ci. Privilégiez un mot de passe contenant des lettres majuscules, minuscules, chiffres et caractères spéciaux.

5. Si l'inscription réussit, un message de confirmation s'affiche. Vérifiez votre boîte mail pour valider votre compte (si l'activation par email est activée sur votre instance).
6. Une fois votre compte activé, revenez sur la page de connexion.

## Se connecter

1. Sur la page de connexion, renseignez votre **nom d'utilisateur** et votre **mot de passe**.
2. Cochez la case **"Garder la session ouverte"** si vous souhaitez rester connecté(e) entre deux visites (utile si vous utilisez votre ordinateur personnel).
3. Cliquez sur le bouton **"Connexion"**.

⚠️ Attention : si vous ne cochez pas cette case, votre session expirera quand vous fermerez le navigateur.

4. En cas d'erreur (identifiant ou mot de passe incorrect), un message rouge s'affiche. Vérifiez vos identifiants et réessayez.

## Découvrir l'écran d'accueil

Après connexion, vous êtes redirigé(e) vers l'accueil. Le contenu de cette page dépend de votre rôle :

- **Responsable / Administrateur** : tableau de bord avec indicateurs clés (nombre de projets, tâches complétées, tâches en retard, membres de l'équipe), graphiques et actions rapides
- **Développeur** : tableau de bord personnel (mes tâches assignées, mes projets, activité récente)
- **Autre utilisateur** : message de bienvenue avec invitation à créer un projet ou à se connecter

## Navigation générale

L'interface est organisée autour d'une **barre latérale** (côté gauche) et d'une **barre supérieure**.

### Barre latérale

La barre latérale donne accès à toutes les sections principales :

- **Accueil** : retour à la page d'accueil
- **Mes Tâches** : vue personnelle de toutes vos tâches assignées
- **Projects** : liste de tous vos projets
- **Sprints** : (visible quand vous êtes dans un projet) planification et suivi des sprints
- **Epics** : (visible quand vous êtes dans un projet) regroupement thématique des tâches
- **Tasks** : (visible quand vous êtes dans un projet) liste des tâches du projet
- **Discussion** : (visible quand vous êtes dans un projet) chat de projet

En bas de la barre latérale, la section **Paramètres** propose :

- **Profil** : modifier vos informations personnelles
- **Thème** : basculer entre le mode clair et le mode sombre
- **Langue** : changer la langue de l'interface (si plusieurs langues sont disponibles)
- **Déconnexion** : fermer votre session

💡 Astuce : la barre latérale est rétractable (bouton flèche en haut) pour gagner de la place sur les petits écrans.

### Barre supérieure

La barre supérieure contient :

- Le **logo** de l'application (clic pour revenir à l'accueil)
- La **cloche de notifications** : affiche les notifications non lues (badge rouge avec le nombre)
- La **recherche globale** (raccourci clavier `Ctrl+K` ou `Cmd+K`) : permet de rechercher rapidement un projet, une tâche, etc.
- Le **menu utilisateur** (avatar ou icône utilisateur) : accès au profil, mot de passe et déconnexion

## Changer de thème (clair / sombre)

1. Cliquez sur le bouton **Thème** dans la section Paramètres de la barre latérale, ou sur l'icône soleil/lune en haut à droite de la page de connexion.
2. L'interface bascule immédiatement entre le mode clair et le mode sombre.

## Changer de langue

1. Dans la section **Paramètres** de la barre latérale, cliquez sur **Langue**.
2. Sélectionnez la langue souhaitée dans la liste déroulante.
3. L'interface est traduite immédiatement.

## Se déconnecter

1. En bas de la barre latérale, cliquez sur votre nom d'utilisateur pour ouvrir le menu.
2. Cliquez sur **Déconnexion**.
3. Vous êtes redirigé(e) vers la page de connexion.

⚠️ Attention : toute modification non sauvegardée sera perdue.
